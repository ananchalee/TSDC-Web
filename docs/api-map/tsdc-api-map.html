  • ซอร์สที่อ่านเป็นสำเนาบนเครื่อง dev ตัวที่รันจริงของ /api อยู่ที่ D:\Project TSDC-internal\API\tsdc-project\server\api.js ซึ่งคนละที่กับที่แก้โค้ด ถ้าสองตัวไม่ตรงกัน เอกสารนี้จะตามตัวบนเครื่อง dev
  • 6 endpoint แมปไม่ได้ — Get_TRANSPORTATION_NAME, get_ordership_delivery_partial, get_ordership_delivery_daily, get_ordership_delivery, update_ordership_delivery, cancel_ordership_delivery ไฟล์ซอร์สของ API ที่มีบนเครื่องนี้ไม่มี endpoint พวกนี้ (สำเนาเก่ากว่าตัวที่รันจริง) จึงยังไม่รู้ว่าใช้ตารางอะไร
  • ชื่อตารางได้จากการอ่านข้อความ SQL ไม่ได้รันจริง endpoint ที่ประกอบ SQL เป็น string จากค่าที่ frontend ส่งมา (เช่น conditiontracking) อาจมีตารางที่มองไม่เห็นจากซอร์ส
  • stored procedure ยังไม่ได้ไล่ต่อ ถ้า endpoint ไปเรียก procedure ตารางที่ procedure นั้นแตะจะไม่ปรากฏที่นี่
  • Express ไม่สนตัวพิมพ์เล็กใหญ่ของ path — frontend เรียก matchItemInConSorter แต่ API ประกาศชื่อ matchItemInConSORTER ใช้งานได้ปกติ เอกสารนี้จับคู่แบบไม่สนตัวพิมพ์
